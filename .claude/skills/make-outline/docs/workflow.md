## 작성 워크플로우

올바른 블로그 글을 작성할 때 다음 순서를 따르세요:

1. **주제 명확화**: 사용자가 원하는 주제와 대상 독자를 확인
2. **개요 작성**: 주요 섹션과 다룰 내용을 bullet point로 정리
3. **초안 작성**: 각 섹션을 위 가이드에 따라 작성
4. **코드 예시 추가**: 필요한 곳에 설명과 함께 코드 삽입
5. **결론 작성**: 핵심 내용 3가지를 bullet point로 요약
6. **최종 검토**: 어조, 구조, 코드 설명이 가이드를 따르는지 확인

## 프롬프트로 글을 작성하기 위한 단계별 가이드

1. 스코프 확정 — 지금 이 대화. 독자·길이·깊이를 먼저 고정한다.
2. 아웃라인 잡기 — "무엇을 이 글의 축으로 삼을지"를 한 문장으로 정하고, 섹션별 뼈대를 만든다.
3. 정보 수집 — 아웃라인의 각 섹션에 필요한 재료만 목적성 있게 찾는다. (공식 문서, 웹 검색, 직접 실험 등)
4. 초안 작성 — 톤앤매너 가이드에 맞춰 실제 글을 쓴다.
5. 다듬기 — 체크리스트로 점검한다.
